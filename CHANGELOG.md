# Changelog – MP4 Fix (OE-Alliance)

## 3.2 (2026-10-13)
- New: **Movie info** – INFO key, Blue = Menu → *Movie info*, or MENU in the movie list →
  *MP4 Fix - movie info*. Quality (4K / Full HD / HD, HDR10, HLG, Dolby Vision profile), video
  (codec, resolution, frame rate, bit depth, bitrate), all audio tracks (language, codec,
  Dolby Atmos, 5.1, sample rate, bitrate), all subtitle tracks and the MKV status. MP4 and MKV, read-only.
- Compiled build for ARMv7 + Python 3.14 (OpenBlackHole 6.0).

## 3.1 (2026-10-04)
- Native look that follows the colours of the active skin; larger colour keys.

## 3.0 (2026-10-02)
- First version for OE-Alliance images (OpenBlackHole).
- Safe playback with ExtePlayer3 (ServiceApp): the standard player freezes the receiver when
  subtitles are switched during playback.
- Make MKV: video and audio copied bit-for-bit, tx3g subtitles as SRT, Slovak default subtitles.
- Quick MKV or TEST of the first 1, 2 or 3 minutes.
